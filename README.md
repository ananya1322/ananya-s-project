# IBM Cognos Analytics – RetailPulse Sales Practicals

## 📌 Project Overview

This repository contains six practical exercises completed using **IBM Cognos Analytics** to understand report creation, data filtering, sales analysis, crosstab reporting, prompt design, and dashboard development.

The project uses the RetailPulse Sales package and RetailPulse customer data to explore how business intelligence tools transform raw data into meaningful reports and visual insights. Each practical focuses on a specific Cognos Analytics feature and demonstrates its application in retail business analysis.

## 🎯 Objectives

- Learn the fundamentals of IBM Cognos Analytics Reporting.
- Create and format sales reports using list reports.
- Apply filters and prompts to analyze specific regions and time periods.
- Summarize sales data using crosstab reports and aggregate functions.
- Design interactive reports using value, date-range, and cascading prompts.
- Develop a customer insights dashboard with charts, summary cards, and shared filters.

## 🛠️ Tools and Technologies

- **IBM Cognos Analytics** – Report creation, data analysis, and dashboard development.
- **RetailPulse Sales Package** – Sales data source for reporting practicals.
- **RetailPulse Customers Data Module** – Customer data source for dashboard development.
- **GitHub** – Project documentation and practical file management.

## 📚 Practicals Included

### Practical 1: Generate a First RetailPulse Report
Created a basic list report using Region, Product Category, and Sales Amount. Executed the report to display data from the RetailPulse Sales package and saved it for future use.

**Key Learning:** Report creation, data source selection, list report design, report execution, and saving reports.

### Practical 2: Build a Grouped RetailPulse Sales List Report
Developed a detailed sales report containing Region, Store Name, Product Category, Quantity, and Sales Amount. Applied grouping by Region and Store Name, formatted numerical values, and added aggregate totals.

**Key Learning:** Data grouping, currency formatting, numeric alignment, and summary calculations.

### Practical 3: Filter RetailPulse Sales by Region and Date
Applied a Region filter and an advanced date-range filter to display sales records for a specific region and reporting period. Explored prompted filters to make the report reusable for different regions.

**Key Learning:** Detail filters, AND conditions, date filtering, and parameterized report interaction.

### Practical 4: Build a RetailPulse Region–Product Crosstab
Created a crosstab report with Region as rows and Product Category as columns. Added Sales Amount and Quantity as measures and enabled row and column summary totals.

**Key Learning:** Crosstab design, data aggregation, multiple measures, and grand totals.

### Practical 5: Build the RetailPulse Sales Prompt Report
Designed an interactive prompt page containing Region, date-range, and cascading Store prompts. Connected the prompts to report filters and configured the report to display results based on user selections.

**Key Learning:** Value prompts, date-range prompts, cascading prompts, filter associations, and interactive reporting.

### Practical 6: Build the RetailPulse Customer Insights Dashboard
Designed a customer insights dashboard incorporating a summary card for active customers, a line chart for new versus returning customers, a bar chart for loyalty segments, and a Region filter.

**Key Learning:** Dashboard design, customer analytics, data visualization, and interactive filtering.
